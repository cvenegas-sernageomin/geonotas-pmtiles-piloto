# Piloto PMTiles — Geonotas

Repo temporal de prueba para evaluar si migrar la capa "Cartas SG" de
[Geonotas](https://cvenegas-sernageomin.github.io/geonotas/) de `L.imageOverlay` (WebP completo
decodificado en memoria) a raster PMTiles (tiles, solo lo visible en pantalla).

- **Móvil:** https://cvenegas-sernageomin.github.io/geonotas-pmtiles-piloto/
- **Escritorio (comparación lado a lado):** https://cvenegas-sernageomin.github.io/geonotas-pmtiles-piloto/escritorio.html

2 cartas de prueba (GB-141-142, GB-192-193), cada una en su WebP original y su versión PMTiles.
No es parte de Geonotas — es un repo descartable, se puede borrar cuando termine la evaluación.
